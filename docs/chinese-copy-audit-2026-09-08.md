# 组件与示例中文化盘点

本次检查覆盖 38 个组件 Vue 文件、36 个 Storybook 示例文件和预览资源。组件内置文案与示例展示文案统一使用中文；组件名、代码标识、格式名称及调用方传入的内容保持原意。

## 表格按钮间距

- 排序和重置原本已经使用 `BingButton`，但局部样式清除了内边距和最小高度，导致悬停背景紧贴文字。
- 两者统一为上下 4px、左右 8px 内边距，最小高度 28px。
- 排序按钮通过外边距补偿保持表头文字对齐，说明图标保留独立间隔；拖拽预览与真实表头共用几何尺寸。
- 原有表格行高保持不变：紧凑 36px、默认 40px、宽松 44px。连续排序、固定列和重置仍可直接响应。

- `BingButton` 等组件名、品牌名、属性/事件/插槽名称、类型、枚举值、代码示例、JSON 字段和技术标识。
